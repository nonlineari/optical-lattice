# Carrier

Retrieved from https://iama.cc/optical-lattice/ on 2026-10-05.

## Carrier

Projected tesseract containing a carbon-stone lattice. Encoding is refractive-index variation plus Hellschreiber pixel density. Readout is multi-axis coherent laser light. Interference patterns reconstruct visual tokens and sound-like payloads.

Claimed properties: multi-directional readability, permanent light and ink commitment, hybrid production (continuous tape for volume, lattice objects for critical archives), Analog↔Digital control.

## Unfolding

One lattice, three realisations.

1. Desktop dock. Recessed multi-axis laser bay.
2. Cockpit retro-fit. Secure centre-console dock, live mobility and momentum vectors, ASR envelopes.
3. Phone-back. Carbon-fibre panel unfolds from folded, to hinged, to a fully three-dimensional tesseract. Compact laser diode and sensor array.

## Signal path

Laser scan → optical reconstruction → ASR envelope shaping → additive / sub-harmonic synthesis → mobility / momentum vector → NLS interface → audio DAC.

## Metatronics note on the page

The page replaces electronic current with light paths: refractive lattices and printed optical waveguides. CAP2N is described as dual-redundant deterministic networking, atomic-clock sync, Noise handshakes, parallax multi-axis addressing, lattice as routing medium.

Treat CAP2N and metatronics as design language for the installation, not as a built network stack, until a protocol note is added.
